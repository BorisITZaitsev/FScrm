# Fit Service CRM

CRM-система для автосервиса Fit Service, реализованная на ASP.NET Core (.NET 10) с хранением данных в SQLite через Entity Framework Core.

## Запуск

```powershell
dotnet restore
dotnet run --project .\FitServiceCRM\FitServiceCRM.csproj
```

По умолчанию приложение запускается на `http://localhost:5253`.

## Роли и интерфейсы

### Системный администратор

Вход под `admin`.

Доступны разделы:
- `Общий вид`
- `Пользователи`
- `Сотрудники`
- `Услуги`
- `Клиенты`
- `Заказ-наряды`

Администратор может:
- управлять учетными записями;
- управлять сотрудниками, клиентами и услугами;
- редактировать карточки клиентов, включая автомобили и представителей;
- редактировать заказ-наряды, состав автомобилей и работы.

### Руководитель сервиса

Вход под `manager`.

Доступны разделы:
- `Общий вид`
- `Заказ-наряды`
- `Клиенты`
- `Сотрудники`
- `Услуги`

Руководитель сервиса может:
- просматривать данные по клиентам, сотрудникам, услугам и заказ-нарядам;
- открывать карточки связанных объектов;
- просматривать историю заказ-наряда;
- согласовывать заказ-наряд;
- создавать запрос на изменение заказ-наряда.

### Мастер-приемщик

Вход под `master`.

Доступны разделы:
- `Общий вид`
- `Заказ-наряды`
- `Диагностика`
- `Клиенты`
- `Сотрудники`
- `Услуги`

Мастер-приемщик может:
- создавать и редактировать заказ-наряды;
- менять статусы заказ-нарядов;
- добавлять и изменять работы;
- связывать заказ-наряд с несколькими транспортными средствами;
- создавать и редактировать диагностические заключения;
- создавать заказ-наряд на основе диагностики;
- просматривать клиентов, сотрудников и услуги без их редактирования.

### Клиент

Вход под `client` или `fleet`.

Доступны разделы:
- `Общий вид`
- `Запись на услугу`
- `Профиль`
- `Транспортные средства`
- `Заказ-наряды`
- `Диагностика`

Клиент может:
- редактировать свой профиль;
- добавлять свои транспортные средства;
- редактировать транспортные средства, если по ним нет активных заказ-нарядов;
- создавать запись на услугу или диагностику;
- просматривать свои заказ-наряды;
- согласовывать заказ-наряды;
- отправлять запросы на изменения;
- просматривать диагностические заключения;
- подтверждать ознакомление с диагностикой.

Для юридического лица дополнительно доступна работа с несколькими представителями.

## Seed-данные

При первом запуске автоматически создаются демонстрационные данные:
- сотрудники разных ролей;
- физические и юридические лица;
- представители юридических лиц;
- транспортные средства;
- категории услуг и услуги;
- записи на услугу;
- диагностические заключения;
- заказ-наряды в разных статусах;
- уведомления;
- история изменений и согласований.

Если приложение обнаруживает устаревшую локальную SQLite-базу без новой схемы, база пересоздается автоматически.
