# Fit Service CRM

Веб-CRM для станции технического обслуживания, разработанная по материалам ВКР о CRM-решении для Fit Service. Система реализована на ASP.NET Core (.NET 10), хранит данные в SQLite через Entity Framework Core и при первом запуске автоматически создает демонстрационную базу.

## Запуск

```powershell
dotnet restore
dotnet run --project .\FitServiceCRM\FitServiceCRM.csproj
```

После запуска откройте `http://localhost:5253`. Если порт занят, адрес будет показан в консоли `dotnet run`.

## Демо-доступы

| Роль | Логин | Пароль |
| --- | --- | --- |
| Администратор системы | `admin` | `Admin2026!` |
| Мастер-приемщик | `master` | `Master2026!` |
| Руководитель сервиса | `manager` | `Manager2026!` |
| Клиент сервиса | `client` | `Client2026!` |

## Ролевые интерфейсы

### Администратор системы

Войдите как `admin`. Доступны управление пользователями и ролями, включение/отключение учетных записей, добавление сотрудников, клиентов и услуг, просмотр последних заказ-нарядов и документов.

### Мастер-приемщик

Войдите как `master`. Доступны создание, изменение, мониторинг и удаление незавершенных заказ-нарядов, смена статусов, добавление работ на согласование, формирование заключений диагностики и отчетов о выполнении работ.

### Руководитель сервиса

Войдите как `manager`. Доступны списки заказов, сотрудников, клиентов и услуг, а также аналитический модуль: фильтрация по услуге, сотруднику и периоду, расчет тренда методом МНК, оценка спроса методом моментов и ММП, прогноз заказов и выручки.

### Клиент сервиса

Войдите как `client`. Доступны редактирование контактных данных, добавление транспортных средств, запись на диагностику или услугу, просмотр истории работ, уведомлений и согласование/отклонение предложенного списка работ.

## Данные

Seed-данные создаются при первом запуске, если в базе нет пользователей. В демо-базе есть сотрудники сервиса, клиенты, транспортные средства, услуги, заказ-наряды за несколько месяцев, диагностические документы, отчеты и уведомления.
